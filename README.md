# iCloud Calendar MCP website

The site at https://mcp.onekash.org: the landing page and setup guide for
[iCloud Calendar MCP](https://github.com/icloud-calendar-mcp/icloud-calendar-mcp). Built with
Docusaurus and published to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

```bash
npm ci
npm start          # local preview with live reload
npm run build      # static site in build/
npm run serve      # serve build/
```
